# Navigation guidelines

Target: Flipper Zero, 128x64 monochrome screen.

- Up/Down: move selection.
- OK: select or confirm.
- Back: return or safely cancel.
- Left/Right: change value only when clearly indicated.
- Frequently used tools should be reachable in at most three menu levels.
- Use short labels and actionable errors.
- Every app must include a help page, version and compatibility information.

Proposed main menu:
1. Quick Tools
2. RF & Signals
3. Access & Tags
4. Wireless
5. Hardware
6. Sessions & Logs
