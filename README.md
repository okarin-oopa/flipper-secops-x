# Flipper SecOps X

A local-first, open-source extension suite for Flipper Zero and compatible firmware, focused on authorized security assessment, diagnostics, protocol analysis and documentation.

## Project principles
- Reuse supported existing apps before creating duplicates.
- Prefer standalone FAP applications to firmware forks.
- Keep documentation, tests, and compatibility notes with each feature.
- Do not commit credentials, private access tokens, captured sensitive identifiers, or private assessment data.

## Getting started
1. Clone this repository locally.
2. Read `docs/architecture/OVERVIEW.md` and `tasks/ROADMAP.md`.
3. Review `tasks/BACKLOG.md` for the first milestone.
4. Pin the Momentum/Flipper SDK version before starting a build.

Build scripts will be added after the target SDK version is verified.
